Política de Privacidade - Kick Watch

Última atualização: 30 de agosto de 2026

Esta Política de Privacidade descreve como o aplicativo Kick Watch ("o App"), desenvolvido por ChoCkyTV, coleta, usa e protege dados ao ser usado no Discord.

1. Dados que coletamos

Ao instalar ou usar o App, podemos processar os seguintes dados:

  • Dados do Discord: ID do usuário, ID do servidor e/ou canal, e nome de usuário, fornecidos pelo próprio Discord quando você interage com o App (via OAuth2 ou dentro da Activity).
  • Dados públicos da Kick.com: informações públicas de status de transmissão (ex.: se um canal está ao vivo, título da live) obtidas via API pública da Kick, sem necessidade de login na Kick.

2. Como usamos os dados

Os dados coletados são usados exclusivamente para o funcionamento do App — por exemplo, exibir o status de uma transmissão dentro do Discord. Não vendemos nem compartilhamos esses dados com terceiros para fins de publicidade.

Você pode solicitar a remoção do App do seu servidor ou conta a qualquer momento pelas configurações do próprio Discord. Para solicitar a exclusão de dados eventualmente armazenados, entre em contato pelos canais abaixo.
